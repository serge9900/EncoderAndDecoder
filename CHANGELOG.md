# Changelog

## 2.8 — About and GitHub
- Added Info/About dialog with Sergey Vardanyan credit.
- Added GitHub profile button in the header.

## 2.7 — Paste improvements
- Changed the Paste button to replace the source text rather than append duplicates.

- Added instant English / Russian switching and remembered choice.
